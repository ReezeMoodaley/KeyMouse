## Executed checks (2026-10-11)

- Rust: 44 passing regular tests; timing and the interactive native drag test run separately. The timing test is a measurement, not a pass/fail performance threshold.
- Frontend: 15 passing tests, including all new toggles, tool command routes, explicit calibration activation and profile editing.
- Rust formatting, Clippy across all targets/features, TypeScript and ESLint passed.
- Final production NSIS installer rebuilt successfully. Embedded manifest retains Common Controls v6, `asInvoker` and PerMonitorV2. The release executable passed the Windows loader and exited successfully through existing-instance handoff; a separate fresh-instance release UI and installer installation/uninstallation were not exercised.
- Isolated native command harness: 15 checks passed, including browser text selection with left-button held before movement, three repetitions in each of Normal, Turbo and Precision. It preserves the normal running application/settings, restores cursor coordinates and gracefully stops its diagnostic instance. Report: `src-tauri/target/native-smoke-report.json`.
- Native Precision: ten internal synthetic taps moved the actual cursor exactly ten physical pixels; final-direction release stopped further movement.
- Drag output uses ordered absolute mouse input for movement, button transitions and wheels. Button transitions include the current physical cursor position; ordinary movement does not repeat a held button's down event. Coordinate tests cover every pixel of representative desktop widths and negative origins. The interactive native drag regression also checks repeated text selection and title-bar movement across all three modes. Physical keyboard/firmware acceptance remains separate.
- The user confirmed window dragging and text highlighting worked after the development build reloaded this fix. This is focused functional confirmation, not completion of the full hardware/performance acceptance checklist.
- Button-only scheduling after long idle no longer treats an irrelevant movement timestamp as a movement stall. This prevents a fresh drag press being canceled solely because the directional integrator had been idle; the regression uses button state without injecting clicks.
- Restricted sandbox initially denied displayed native magnification. The same check passed with normal desktop access. This is a desktop permission distinction, not an API fallback or suppressed failure.

Pure debug-build calculation timing, seven 100,000-tick runs per implementation, median: frozen v1 **60.3 ns/tick**, refinements disabled **88.8 ns/tick**. This saturated cardinal hold workload excludes Windows API calls, input, scheduling, UI and physical hardware. The extra approximately 28.5 ns corresponds to roughly 0.00071% of one core at 250 Hz for pure calculation only. It is not a whole-process CPU or latency measurement, and hardware timing/jitter remains unmeasured.
